# Go Neighbors

**Go Neighbors** is a neighborhood community app designed to help people connect with those living nearby. It makes it easier to exchange skills, offer or request help, share resources, and build trust within local communities.

## About the project

Go Neighbors started as a hackathon concept and is being developed and tested as a minimum viable product (MVP). The project explores how a simple digital platform can encourage meaningful connections and everyday collaboration between neighbors.

## Key features

- **Local connections:** Connect with people in your neighborhood.
- **Give and receive help:** Offer your skills, time, or resources, and find support nearby.
- **Community participation:** Discover ways to contribute to a more connected neighborhood.
- **Mobile-first experience:** Access the app on your phone and add it to your home screen for convenient use.

## Try the app

Open the web app at **https://go-neighbours.lovable.app**.

To add it to your phone's home screen:

- **iPhone (Safari):** Open the link in Safari, tap **Share**, then **Add to Home Screen**.
- **Android (Chrome):** Open the link in Chrome, tap the three-dot menu, then **Add to Home screen** or **Install app**.

If you open the link in an in-app browser such as WhatsApp, switch to Safari or Chrome first.

## Local development

Prerequisites: [Node.js](https://nodejs.org/) and npm.

```bash
git clone https://github.com/theoriginalnatewashere/goneighbours.git
cd goneighbours
npm install
npm run dev
```

Open the local URL printed by the development server.
